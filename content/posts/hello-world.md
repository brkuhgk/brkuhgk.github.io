I kept losing things. A book someone recommended over dinner, a half-formed idea
about a project, the name of a talk I wanted to watch. Notes apps didn't stick
because nothing was ever *finished* enough to feel worth keeping.

So this is the low bar version: a place where an unfinished thought is the
point.

## How this works

Every post here is one markdown file in `content/posts/`. To write a new one I
add a file, commit, and it's live in about a minute. No CMS, no database, no
login screen.

The lists — books, events, the hundred things — are the same idea. One file per
list, and I append a line whenever something comes up.

```bash
npm run new "The title of the thing"
```

That's the whole workflow.

## What goes here

Roughly three kinds of thing:

- **Posts** — anything long enough to need paragraphs.
- **Lists** — running collections that never really finish.
- **Notes to self** — mostly the "now" page, which I update when the answer to
  "what are you working on?" changes.

> The best time to start writing things down was ten years ago. The second best
> time is a Tuesday afternoon.

Delete this post whenever you like — the file is
`content/posts/hello-world.md`.
